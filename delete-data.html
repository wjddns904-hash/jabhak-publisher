Data Deletion Instructions

For Jabhak Multiplatform Publisher

The current desktop version does not require a central cloud account database operated by the App. Most project and credential data is stored locally on the creator's device.

1. Revoke TikTok access

Remove/revoke access for Jabhak Multiplatform Publisher in TikTok account settings.

2. Revoke Instagram / Meta access

Remove the application's authorization in the connected Meta/Instagram account settings.

3. Revoke Google / YouTube access

Remove the application's access in your Google Account third-party access settings.

4. Delete local credentials

Delete locally stored authorization and API credential files used by the App, including local environment/token files created for enabled integrations.

5. Delete local projects and analytics

Delete project folders and locally saved analytics/performance files to remove generated content, publishing records, and local performance snapshots.

6. Additional request

If you believe the operator holds information that cannot be removed using the steps above, contact YOUR_CONTACT_EMAIL with the subject Data Deletion Request.
